# Luna — Core Skills Bundle

Skills are inert prompt + docs bundles — no scripts, no executables.
Luna loads these into context when the task matches.

Planned canonical skills (milestone 1 onward, see
`docs/design-studio-plan.md`):

| Skill | Purpose |
|---|---|
| `scope-a-session.md` | Bind "for this" to the conversation's subject; resolve verb (direct / critique / codify) and depth. |
| `choose-boards.md` | Filter the question bank to what matters for the scope. |
| `write-options.md` | Generate 2–4 distinct, repo-grounded options per board with tokens, facets, and a recommendation. |
| `compose-mix-and-match.md` | Merge facets from several options into one confirmable option. |
| `close-a-session.md` | Summarize decisions, hand rule-shaped notes to Mika, write the DESIGN.md narrative. |
| `finish-review.md` | Review Mika's build against the session's decisions. |

Creator-authored skills accumulate as kind: creator overlays; they are
never auto-published (TD-902).
